## 1. Summary

Five fixes, in order of how much a player or the app feels each one.

- **Task 210:** a room restarted mid-play replays its intro over the *old* room's last frame. The swoop and the landing ring aim at the old position, and then everyone snaps to spawn. The 2.4 s hold from Task 110 opened this gap.
- **Task 211:** production builds ship the frame bench's client bundle in `/_astro/`. It holds room 09 in full (cache, plate, chamber), and anyone can fetch it while `/bench` itself returns 404. That defeats ADR 0007.
- **Task 212:** the frame bench only pans sideways, so it never times the vertical pan. The run measured that case at 1.11×.
- **Task 213:** the sun glow switches off on every frame of a vertical pan and snaps back at full strength when the camera stops.
- **Task 214:** half of the "a code swatch is never a gradient" test can never fail.

Each task starts by reproducing its finding. A finding that will not reproduce is not fixed; it gets a dated line in `specs/backlog.md` instead. Each fix starts with a test that fails on today's code. The test is shown red by breaking the guarded code on purpose, through a script that asserts the text it replaces, never a bare `sed`. No test is weakened or deleted, and nothing new is installed.

## 2. Requirements

1. **FR1 (a restart starts clean).** When a room restart vote passes, every seat and watcher gets the restarted room's tick-0 view before the intro plays. The rise, swoop and landing ring then show the restarted room at spawn, not the old room's last frame.
2. **FR2 (no room text in a public asset).** A production build (`pnpm build` without `BENCH=1`) contains no bench page and no bench bundle. No file under `dist/client` contains room text. The bench still works when it is built and run with `BENCH=1`.
3. **FR3 (the bench sees vertical pans).** The frame bench moves the camera vertically as well as sideways, so the horizon changes and the sky's pan path is timed. `--compare` runs against the existing baseline (`review/diorama/bench-baseline.json`), which is not re-recorded.
4. **FR4 (the glow holds through a pan).** No frame of a vertical pan drops the sun glow, outside high contrast. While the horizon moves, the last cached sky is drawn, a few pixels stale at most. It is repainted once the horizon settles.
5. **FR5 (a swatch test that can fail).** For every station type, the test fails if a code swatch is painted with anything other than its code's plain colour.
