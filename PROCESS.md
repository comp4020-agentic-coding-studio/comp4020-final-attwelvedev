# Process overview

A three-player browser co-op heist: one player can't see, one can't hear, one can't speak, and they must coordinate through whatever each role is still allowed to send (callouts, text, clips, faces, marks; [ADR 0011](doc/adr/0011-channels-by-method.md)). The brief wants an app that is better because others use it concurrently; my first, a shared pantry, answered that weakly, since households talked in person and the app stayed out of the way. I stopped mid-phase instead of polishing. A spec, four ADRs and a plan came before any code ([`22bbaef`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/22bbaef)), the pantry was committed as it stood ([`a53b516`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/a53b516)) and tagged, then deleted ([`463b7b6`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/463b7b6)). The harness carried over.

**Stack.** A browser sent the map would expose it to Can't see through dev tools, so a `ws` server runs an authoritative headless simulation and sends each client only what its role perceives ([ADR 0007](doc/adr/0007-websocket-game-server-with-per-role-perception.md)). I rejected peer-to-peer (no referee) and a game framework (heavy for one 256 MB machine, and it diffs state assuming everyone sees the same). Astro, Node and SQLite stayed ([ADR 0001](doc/adr/0001-astro-node-preact-sqlite-stack.md)). Bots, the linter and specs run the simulation directly; the cost is a hand-rolled lobby, voice and reconnect layer.

**Workflow.** `/brainstorm-feature` writes a spec (with a read-only subagent design pass with Anthropic's `/frontend-design`, [`2356203`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/2356203)), `/plan-feature` cuts phased TDD plans, and `/execute-plan` reviews each plan against the real code and stops when they disagree. Two things were added once playtests showed what checks missed: `pnpm playtest`, where bots drive three real browser tabs through every room while frame invariants are checked, and a `/product-review` skill that critiques the repo as a product manager (RICE and Kano) from the playtest write-ups ([`e31f468`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/e31f468)). Corrections land in `CLAUDE.md` or a spec and are logged in [`PROCESS_LOG.md`](PROCESS_LOG.md). The chains below are where my direction changed the outcome.

## 1. Making Can't see matter, in three steps

[Playtest 2](playtests/2026-10-14-playtest-02.md) called Can't see "deadweight": it follows directions while the others lead. First answer: a different role leads each beat, which still left one leader and two followers. I dropped lead beats for stations and gear, puzzles whose clue, control and feedback no single role perceives, and declined role abilities because they prescribe strategy ([ADR 0017](doc/adr/0017-balance-by-presence-stations-and-gear.md), [`367098f`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/367098f)). Can't see still had little to do, so I reversed the abilities call for exactly one thing that fits the character: braille plates only Can't see can read, each carrying a number the room needs ([ADR 0023](doc/adr/0023-braille-plates-only-cant-see-reads.md)). [Playtest 3](playtests/2026-11-08-playtest-03.md) found braille helpful, and abilities stay declined in general so the exception cannot spread ([`d20ebbf`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/d20ebbf)).

## 2. "Cleared by bots" had to mean "clearable by a person"

Bots cleared my stations draft in every rotation, yet I could not solve one station: the clues never reached a person, because bots read answers straight from the simulation. Fixing each room's clues would have left the test unable to catch the next gap, so I stopped the phase and fixed the test. Bots now solve only from what their role perceives, a linter fails a clue no person can receive, and the heist became nine short rooms ([`73cd110`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/73cd110), [ADR 0018](doc/adr/0018-perception-only-bots-and-paced-rooms.md)). Rooms 2 and 3 then stopped clearing: in room 3's dark corridor only Can't see perceives the guard, and a bot in that seat tells no one. The only lever was a "hold up" warning face; warning on every hazard flooded the team with faces and it never left spawn, and warning on loud ones only left it caught 35 times. Each setting fixed one failure by causing the other, which is tuning to a test, so I reverted, kept the harness and recorded the rule as not met ([`d00bc84`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/d00bc84)).

## 3. The last week: an overnight driver, with me as the review queue

With the budget raised for the final week, an unattended driver ran plan phases overnight in fresh sessions, with Opus assigned to phases the setup agent judged complex and Sonnet to the rest ([PR #3](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/pull/3): 34 units, each closed by a `Unit done` commit). Units can pass their own checks and still be wrong, so each got a batched read-only review, then a pass that tried to refute each finding; what it could not settle was parked for me ([`2aceafb`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/2aceafb)). The automated `/code-review`s caught real bugs: the last found that spinning room 6's radio knob solved it, so players could skip the braille plate (I had found it in play too). The fix was the rule and the lint together, since `lintPlates` skipped radios ([`2a6fdee`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/2a6fdee)). My corrections went in the queue: I asked why a glass fix was parked, learned it had run out of budget, and told the agent the rule rather than loosening an older test ([`65a2982`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/65a2982)). A cold review found wire-snip tests green while the snip never fired in play ([`64ce6fd`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/64ce6fd)), and tasks ticked "not met" or "accepted" when only queued became a failing spec ([`cfcfd89`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/cfcfd89)). Budget also shaped the playtest: three agents playing a heist cost about $55 a run, so I chose `pnpm playtest:review`, a $2 read of that run's screenshots, and left comms and fun to people ([ADR 0028](doc/adr/0028-a-screenshot-review-from-what-a-player-perceives.md)). The skill needed correcting too: its review read playtest 3's two hours as the game's length, but much of that was me taking notes, so I replaced the claim with a measurement the app already makes ([`1c2d58c`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/1c2d58c)).

## 4. Why the game is puzzles, not darkness

[Playtest 1](playtests/2026-10-09-playtest-01.md) showed room 3's dark area was impossible for Can't hear, so I replaced darkness and alarms with familiar escape-room puzzles, introduced slowly. That is only a promise until something fails on it, so `pacing.test.ts` fails any room that brings a third new kind of object ([`c4b7056`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/c4b7056)). My own additions then tested the cap. I ruled that a side job is loot with an owner ([`8144a79`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/8144a79)) and that a braille plate is the answer to a station already taught ([`bb0ed58`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/bb0ed58)), each written into the test with its date, so a third station type still fails.

## 5. Retries, then measuring before replacing

I had been rerunning red checks until green, which hid why they failed. I had the agent run the suite repeatedly: identical failures were bugs, intermittent ones were separate causes, such as a count read against a page other specs were changing. The fix was `pnpm check:flaky`, a `CLAUDE.md` section and a spec that greps the bad shapes; eight full runs passed where before four in six had failed ([`de360e7`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/de360e7)). When CI flakes outlasted a day of patches I replaced browser specs with clockless unit tests. The agent offered seven more; I measured instead of guessing (4 of 4 runs) and left them ([`351e71a`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/351e71a), [`9f43c63`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/9f43c63)).
