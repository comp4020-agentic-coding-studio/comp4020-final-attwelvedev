# Process overview

A three-player browser co-op heist: one player can't see, one can't hear, one can't speak, and they coordinate through channels each role may use. It is my second app; the first was a shared pantry. The first build is deployed. I am now part-way through the play overhaul (`specs/2026-10-19-play-overhaul.md`), which the first two playtests asked for.

## From the brief to this app

The brief wants an app that is more interesting because other people are using it at the same moment. My pantry answered that weakly: households talked in person and the app stayed out of the way. I stopped half-way through phase 05a, because more polish would not have made it any more about co-presence.

The pivot went through the usual route: a brainstormed spec, four new ADRs and a phased plan, committed before any code moved ([`22bbaef`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/22bbaef)). The unfinished pantry was committed as it stood and tagged `archive/pantry-2026-10-08` ([`a53b516`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/a53b516)), so every earlier SHA still resolves. Then I deleted it from `main` ([`463b7b6`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/463b7b6)). The harness carried over, since none of it was about food. The cut was clean: `pnpm check` stayed green and a grep for pantry wording in `src` and `spec` came back empty.

## Stack

Astro on Node with SQLite stayed ([ADR 0001](doc/adr/0001-astro-node-preact-sqlite-stack.md)), because the target is still one 256 MB Fly machine. The real decision was the transport. If the Can't-see browser receives the map and merely doesn't draw it, dev tools expose it. So a `ws` server runs an authoritative headless simulation and sends each client only what its role perceives ([ADR 0007](doc/adr/0007-websocket-game-server-with-per-role-perception.md)). I rejected peer-to-peer, which has no referee, and a game framework, which is heavy for 256 MB and diffs state assuming everyone sees the same thing. Identity is an anonymous device cookie plus a nickname ([ADR 0008](doc/adr/0008-anonymous-device-and-nickname.md)), only heist records persist ([ADR 0009](doc/adr/0009-only-heist-records-persist.md)), and voice is relayed through the server so the deaf rule is enforced there ([ADR 0010](doc/adr/0010-voice-relayed-through-the-server.md)). Because the simulation has no DOM or sockets, bots, the room linter and the specs run it directly.

## Workflow

Work goes brainstorm, plan, execute. Each phase has a TDD plan, and the agent reviews it against the real code first, stopping to ask when they disagree. Mid-phase ideas go to a backlog sorted at the phase boundary. `pnpm check` must be green before each commit, and each commit is one unit of work. Hooks block edits to course-fixed files and deploys from a dirty tree. When I correct the agent I fix the cause, in `CLAUDE.md` or a check, and log it in `PROCESS_LOG.md`. Brainstorming also runs a read-only design pass: a subagent proposes a design plan and wireframes, I amend it, and it revises. I put it there so the first build is already designed ([`2356203`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/2356203)). In the heist spec I replaced its pip row for the channel indicator with an arrow list of receivers, because the pips didn't read, and cut its Can't-speak secret layer ([`22bbaef`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/22bbaef)). It did not make the game usable: playtest 1 still found sheets covering the map, so the design pass sits before playtests, not instead of them.

## Moments that mattered

### Making a promise testable

**Parity became a test that can fail.** In review I noticed plates, crates, the checkpoint and the sequence door made no sound, so Can't see would never learn of them. The obvious fix was to add the sounds. Instead I made the promise the thing to test, and had the agent first write `src/game/parity.test.ts`: one row per sound, typed against the list of sounds so a new sound without a row fails to compile. Each row builds a real situation and checks that Can't see receives the sound, Can't hear sees a change in the same tick, and a caption exists. It went red for ten sounds before any was built, and the rule went into `CLAUDE.md` ([`9459be1`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/9459be1)). It proves the information is sent, not that a person can tell two sounds apart.

**A checkpoint one player could bank for everyone.** One player ran through the dark corridor blind and everyone respawned at the next flag. I changed the rule, not the corridor: a checkpoint sets only when all three are within 1.5 tiles. Four new tests failed first, and a solve test proves the scripted team can still set every flag ([`9459be1`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/9459be1)). The radius is a guess not yet tried on phones.

**A lane along a camera's own wall.** I could hug a wall and walk past a watching camera. Widening one cone would have left room 3 with the same hole. The reproduction showed cameras saw from tile centre, leaving the wall strip outside the cone. They now see from the wall face, and a test walks every legal line across every camera. It failed on exactly y = 1.4 in both rooms before the fix, matching what I'd seen by hand ([`29c95e1`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/29c95e1)).

### Playing it, not just testing it

**Playing it found what a green suite could not.** Task 8 passed 255 tests, then playing it showed a door that stranded a player and a crate that only sometimes moved. Each bug became a failing test first. The crate test failed at all 20 offsets and four directions, passed with the fix, and failed again with it stashed. The reload freeze needed a socket-level test, because a browser test passed with and without the fix, so I deleted it ([`4d86a17`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/4d86a17)).

**A wheel that passed every spec I wrote and failed the first person to use it.** Playing the new comms wheel took a minute and gave eight corrections: I steered a dot instead of aiming with my own cursor, slots overlapped, and sending a mark at a wall replaced the whole game with "Problem". Nudging sizes until a screenshot looked right was the obvious reply. I had the agent find why the specs passed instead. The overlap test compared slot centres, so boxes could overlap and still pass, and the "Problem" screen was a latent bug that any socket error could reach. Geometry now lives in one module that drawing and hit-testing both read, and each correction got a measured spec. One call stayed mine because it changed the design: a 12-slot ring of 48 px targets cannot fit a 350 px phone, so phones get a 4x3 grid ([`7263836`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/7263836)).

**Two screenshot misses, one rule.** Reviewing the HUD I found a countdown that broke at its colon beside a long title and a spectator button that read "VHold to talk". I had looked at both, but at short names and the players' panel. Fixing the two instances would have left the next reused component open, so I added a rule to `CLAUDE.md`: look at a screenshot at the new place and with a longer input before reporting done ([`aaacccc`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/aaacccc)). Each fix started with a spec that failed first.

**Chasing choppy voice without guessing.** I reported choppy voice. The agent measured each stage on the real relay and my real microphone; the pipeline was clean, and only a Guest Chrome profile fixed the live call. The agent was wrong twice (a 64 kbps suggestion that would have broken the 400-byte frame cap, and a feedback loop I had ruled out), both caught by my reply, not a check. Only a real leak and a lag-notice spec shipped ([`9c48f74`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/9c48f74)).

### Refusing to make a test pass

**Retries were hiding five flaky specs.** I had been rerunning red `pnpm check` runs until green. I asked the agent to stop and find causes; raising timeouts would have hidden them. It ran the suite repeatedly and sorted failures: those identical every run were real bugs, and the ones that came and went were five separate causes (stale counts read against a shared server, a window edge set by the runner, a flick timed from the runner, a canvas picture taken on the first half-drawn frame). The first fix for the last one made it fail more often, which sent the agent to sample the canvas rather than guess again. The tool became part of the harness (`pnpm check:flaky`, a `CLAUDE.md` section naming the causes, a spec that greps for the two precise shapes). Eight full runs, half under CPU load, passed 922 each time, against four red runs in six before. A sixth flake it found later I could not reproduce, so I fixed what I could see and logged it as not proven gone ([`de360e7`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/de360e7)).

**Stopping the bots' rule twice instead of tuning them to pass.** Line of sight made the sighted roles blind to a dark zone, and my plan said bots may plan only around hazards they have perceived. Rooms 2 and 3 stopped clearing. The obvious step was to tune until the spec went green. I stopped instead. Every catch came at the edge of room 3's dark corridor, where only Can't see perceives the guard. The one allowed lever, a warning face, fixed one failure by causing the opposite: warn on every hazard and the team sent 70 faces a run and never left the spawns, warn on loud ones only and it was caught 35 times. That is tuning to a test. I kept the harness and the record of what a bot has perceived, reverted the planner, and recorded the rule as not met; it moved to a later phase with the rooms built for it ([`7d3aa6a`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/7d3aa6a), [`b2269d2`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/b2269d2), [`d00bc84`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/d00bc84)). The bench stayed at 3.1–3.4 ms a tick for ten lobbies against a 10 ms budget.

**Bots that look human without being stranded.** For the home page I asked for bots with different paces. Adding every effect at once cleared room 1 slowly or never. The agent switched each on alone across 10–40 seeds and found the guide only decides when Can't see is near a tile centre. Slowness became skipped ticks at full step length, and Can't see never pauses. 200 of 200 seeds clear in 21–25 s, and `attract.test.ts` fails a change that strands the hero. Can't see is slower, not hesitant; real hesitation needs a tolerant guide, so it went to the backlog ([`a2d2f4d`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/a2d2f4d), [`9220b90`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/9220b90)).

**A fresh install would have crashed.** Task 18 demanded a persistence test on a genuinely empty database. It crashed: a pivot migration dropped a table two others still referenced. The agent proposed editing that migration. I refused, because it had already run on the deployed volume, and had it switch foreign keys off only around `migrate()`. A saved run later survived a real redeploy ([`69e35ea`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/69e35ea)).

### Changing the design, not the instance

**Headphones, deferred then redone.** Headphones belong to a seat, but roles rotate, so the wizard's one-time question goes stale. With a deploy pending I declined a quick patch, because the real fix reopens `presetFor` and `LobbySettings`, and parked it with the interfaces named ([`642141a`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/642141a)). Playtest 2 showed the real-life setup being ignored too, and the play overhaul brainstorm folded both into one design: each person answers their own setup, and the server recomputes noise, captions and voice every room. The wizard is removed ([`35dae1e`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/35dae1e)). Waiting cost nothing, because the backlog entry named what to reopen.

## Where it stands

Two playtests drove the play overhaul. Playtest 1, with two friends on laptops, found that Can't speak had little to do and that room 3's dark area was impossible for Can't hear ([`playtests/2026-10-09-playtest-01.md`](playtests/2026-10-09-playtest-01.md), at [`1b34024`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/1b34024)). Playtest 2, with my six-person pod in two lobbies, found Can't see was "deadweight", comms were glossed over and the role reveal was unclear ([`playtests/2026-10-14-playtest-02.md`](playtests/2026-10-14-playtest-02.md), at [`01e5d77`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/01e5d77)). Each finding has a row saying what changes and which check guards it, written into the playtest files ([`f77c61f`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/f77c61f)). I declined one suggestion, giving each role a special ability, because it makes strategies prescriptive.

The play overhaul is specified and planned with ADRs 0011–0016 ([`4eeda6c`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/4eeda6c), [`b0faa2c`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-attwelvedev/commit/b0faa2c)). Phases 01–04 are built and ticked: comms by method, lobbies of six with per-person setup, new lobby and HUD screens, and line of sight. Phases 05–07 are not: the tilted world renderer is in progress, then four new rooms with lead beats, then sound. So the evidence that every role can finish every room, and that Can't see is no longer deadweight, does not exist yet; the only way to get it is to playtest the play overhaul with people, and I may not have the chance to before the final crit.

## Takeaway

Checks catch what I thought to test, and playing the game catches the rest. Each time, the fix goes into a rule or a spec, so the agent can't repeat it, and I confirm a check against the known bug before trusting it. When a test is red, I fix the cause or stop; I don't tune the code or the test until it passes.
